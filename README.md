# VK CHESS – ESP32-2432S028 шахматы с Lichess API

Шахматная программа для платы ESP32 (CYD) с цветным дисплеем и тачскрином.  
Поддерживает игру через интернет с ботом Lichess.

## Возможности

- Игра за белых или чёрных
- Подключение к Lichess Bot с помощью API-токена (требуется аккакунт для бота на lichess.org) 
- Сохранение настроек (WiFi, уровень AI, токен) в LittleFS
- Отображение истории ходов
- Статусная строка с сообщениями и свободной памятью
- Офлайн-режим для отладки (эмуляция ответов Lichess) - для разработиков

## Аппаратное обеспечение

- ESP32-2432S028

## Установка и настройка

1. Установите [PlatformIO](https://platformio.org/) в VS Code.
2. Создайте проект и скопируйте в каталог src все файлы из каталога репозитория src.
3. После запуска игры, для подлюкчения к своему WiFI подключитесь к точке доступа VK_CHESS (пароль 87654321), заполните поля SSID, PASS и API-токен. Сохраните введённые настройки.
4. Выберите за кого белых или чёрных бедете играть. Режим PUZZLE пока не действует.
5. Играйте.
